# FlipYear 2.0 设计规范

依据原产品官方说明和截图，聚焦年度转盘、十二个月日历照片书和照片主题书。

- 界面：#101011 深色背景、#F3EEE5 正文、#AAA69F 次级文字、#DFBD84 杏金操作色；可切换浅色。
- 书页：#FFFDF8 暖纸，按月份使用十二组低饱和色；标题衬线、数字清楚、日历周一为第一列。
- 主导航：年鉴 / 相册 / 今日 / 偏好。阅读器有返回、月份跳转、封面选择、正反翻页和本月照片列表。
- 年份转盘：纵向 scroll-snap，按钮可直接选择；装饰封面具有独立的书脊和纸边。
- 卷页：使用固定版本开源引擎；引擎祖先不做 rotate/skew。竖屏单页、宽屏双页，保留明确按钮。
- 日历：真实日期与闰年，未拍摄日留白；照片预览按完整比例显示。紧凑日期格之外另提供大按钮照片列表入口。
- 动效：550/850/1200ms 上限；减少动效时立即完成翻页。支持键盘和可见焦点。
- 隐私与反馈：系统授权可选完整/部分；只在本地处理。明确区分系统源照片和自建相册备份；日期回退、失效图片、读取失败均有反馈。

UI UX Pro Max 已执行 photography gallery、swipe gesture alternative 等检索。photo calendar dark immersive 无匹配，改用 photography gallery 的内容优先/克制界面建议；具体月历和转盘结构依据官方产品截图确定，不假称数据库提供了对应模板。

已检查 320/375/390/768/844/1440px 与横屏、明暗主题、正反卷页及减少动效。

2.8.1：自建相册照片铺满细边框内部，等比例居中裁切，不拉伸。文字与日期叠在底部，不再预留大块空纸。3D 与兼容阅读器一致；大图查看保持完整原图。UI/UX 检索 photo frame crop aspect ratio 无匹配，改用 image dimension 的响应式建议并以截图与圆形测试图验证裁切和比例。

2.8.2：相册全屏，页形与纹理同时适配以免拉伸，移除占位底板。悬浮「…」披露工具，返回和翻页始终可达，系统栏可临时滑出；尊重安全区与48px目标。沿用已执行的 immersive safe area back navigation 检索结果。
