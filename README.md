# FlipYear 相册书 · 2.5.1 开发版

安卓本地年度照片书的个人实现。黑色书房背景、年度转盘、照片封面、十二个月的日历纸张和卷页动画。

## 使用

1. 保留旧版应用，直接安装 FlipYear-v2.4.0.apk。包名与开发签名沿用 1.0，首次启动会迁移旧版相册。
2. 点击「连接系统相册」，由系统选择照片与视频的授权范围。可授权全部、部分或只授权一类；拒绝后仍可手动制作照片相册。
3. 选择年份，翻开封面，滑动或用按钮翻阅月份；横屏/宽屏显示双页。
4. 点日期查看大图，支持双指缩放、双击放大、拖动和按钮还原；用「查看本月影像」进入列表；视频需再点「播放视频」打开原生播放器。年度封面可选择照片或视频封面。
5. 「相册」中创建主题照片书，可添加照片或视频、编辑文案、日期、顺序与页面样式。轻点页内照片可直接放大；左右滑动继续翻页。导入视频保留独立副本，点页中的播放按钮打开。
6. 「今日」显示往年同月同日的照片；「偏好」提供浅/深色、减少动效、翻页速度、备份、桌面小组件与开源许可。

本版应用图标替换为你提供的照片叠页图，保留上传图片内容。

## v2.5.1 开发版增强

- 年鉴新增「自动翻页／暂停自动翻页」，手动翻页、点击月份、触碰书页、关闭书本或进入后台会暂停。
- 点击系统照片全屏预览时，按需请求更清晰的本地有界 JPEG：一般设备上限 3072px，低内存设备 2048px；日历及普通预览仍按原尺寸，预览缓存按上限清理。**不是原图无损导出**，手动导入的旧照片也无法恢复原始已压缩细节。
- 年鉴月份按日期预建索引，避免为每个日历格反复扫描全年照片；大量封面按每批 72 张逐步显示，控制初次渲染量。自动翻页遇到照片预览、键盘翻页、窗口失焦和查看月份照片即暂停。
- v2.5.0 已通过 GitHub Actions 并生成开发 APK；v2.5.1 需以最新 Actions 构建结果为准。真机尚未验证。

## 照片大图与阅读

- 年鉴日期、主题书照片、今日与时间线统一打开全屏预览；无日期照片也能放大。保留原比例，缩放范围 100%–400%，支持双指、双击、滚轮、放大／缩小／还原按钮，放大后拖动查看。系统预览仍使用有界解码，自建照片仍按原导入尺寸保存，放大不会还原已压缩的细节。
- 大图中的前后按钮／方向键只切换预览；关闭、Escape 或安卓返回键回到原书原页。背景阅读器不可点击，焦点留在大图操作区。
- 书架展示当前年与相邻年份封面，点击相邻书封可切换；月份书堆显示真实相邻月历。月历去掉没有日期的整行，邻近月份纸张随当前月份切换。继续使用原卷页引擎，未引入另一套手势几何。
- 本项目是独立实现；当前尚未达到原版 FlipYear 完全相同的书架、纸张形变与视觉效果。

## 桌面小组件

- 「偏好 → 添加桌面小组件」请求桌面确认；不支持快捷添加时，长按桌面 → 小组件 → FlipYear 桌面回忆。取消添加不会显示成功提示。
- 点小组件右上角齿轮，可为每个实例分别选择「那年今日」或「固定照片」。默认完整呈现照片，可切换填满画框。支持调整大小。
- 那年今日仅查询已授权的系统照片，使用真实拍摄日期匹配往年同月同日，不用入库日期替代；无匹配时显示空状态。按拍摄时间排序，最多轮阅 128 张。多张时点「换图」浏览。
- 固定照片使用系统文件选择器的持久 URI 授权，不要求开放整个照片库。源文件删除或授权撤回后显示不可用；替换、取消选图和移除组件会清理不再使用的持久授权，多组件共享的授权保留。
- 点照片在应用中按完整比例查看。点 ↻ 手动刷新；系统约每 30 分钟请求更新，打开应用、相册变化和授权结果也会刷新。受系统省电和桌面实现影响，定时更新可能延迟，不承诺零点立即更新。
- 单个小组件位图长边不超过 400px，按宿主尺寸收缩；整组 RemoteViews 替换，避免累积位图动作。没有额外后台服务、精确闹钟或网络依赖。照片会显示在桌面，请按自己的隐私偏好设置。

## 主题相册视频与 ZIP 备份

- APK 中打开主题相册，点「添加视频」用系统文件选择器选取，不要求开放整个系统视频库。视频复制到应用私有目录，保留原始内容；删除手机原视频不会影响已经完整导入的副本。
- 每批 1–20 段、单段最多 250MiB、单批合计最多 512MiB。复制中请保持应用开启；复制报错会撤回本批新副本，现有相册保留；强制结束应用后留下的未引用副本，可用清理按钮回收。优先读取容器日期，其次识别文件名中的 YYYYMMDD；无法确认则留空，可在编辑页填写。播放编码能力仍由设备决定。
- 视频页支持原有编辑、排序和移除；填写日期后也会进入年鉴／今日。页面保持静态封面，轻点播放，不在翻页时自动播放声音。
- 含视频的自建相册自动导出 ZIP，包含 manifest.json、照片数据及独立视频文件；纯照片仍导出兼容的 JSON。使用「偏好 → 从视频 ZIP 恢复」，确认后添加新相册，不覆盖现有内容。
- ZIP 最多 200 个独立视频、3000 页、200 本相册；说明文件最多 32MiB，解压合计最多 512MiB。过大时请逐本导出。视频保持二进制流，不转成 base64；备份未加密，请妥善保管。
- 恢复先在私有空目录暂存，校验清单、条目名、数量、大小和 ZIP CRC，再为视频分配新 UUID。缺失、重复、越界路径、损坏或过大的条目会回滚本次暂存。用户取消确认或数据库保存失败时，只撤回本次新副本。
- 原生导入结果先落盘，数据库不可读时保留待处理结果；已保存的操作令牌可避免确认成功后、原生收尾前中断造成重复添加。尚需安卓设备验证真实进程重建和 SAF 生命周期。
- 删除页面或相册后，可在「偏好 → 清理未使用的视频副本」回收空间。先成功保存当前相册状态，再清理无引用副本；仍被其他相册使用的视频保留，手机原视频不删除。
- 私有视频副本会随卸载／清除应用数据删除，务必先导出 ZIP。网页版提供照片功能，视频导入、视频 ZIP 和私有副本播放在 APK 中使用。

## 系统视频

- 连接系统相册后，视频与照片按拍摄日期共同生成年鉴。「今日」也可查看往年同日的视频，日历与列表标注 ▶ 和时长；不自动播放。
- 预览中点「播放视频」打开应用内原生播放器，支持系统播放／暂停及进度拖动，保持画面比例。横竖屏保留同一播放器；切入后台暂停并在停止时释放，返回后保持暂停、恢复位置。
- 视频只保存 MediaStore 引用与元数据，按需生成封面，不把原视频读为 base64，也不转码或修改原文件。预览封面最多 640px，日历／列表按需使用 320px 缩略图。Android 8.0 使用系统小尺寸缩略图，8.1 起使用缩放帧提取。
- 播放仅接收本地 MediaStore 数字 ID，不接受任意文件路径或网络网址；打开前由系统重新检查文件授权。封面提取失败时仍可尝试播放，播放器对缺失文件、撤回授权和不支持的编码显示错误。
- 实际编码支持取决于设备系统，未额外捆绑解码器。尚未在安卓设备验证实际解码、音频焦点、暂停拖动及后台恢复。
- 系统年鉴仍引用手机原始媒体；主题相册视频则保存独立副本并通过 ZIP 备份。桌面小组件继续只显示静态照片。Live Photo／Motion Photo 配对和动态照片还原未实现。

## 照片与日期

- 系统年鉴只保存 MediaStore 索引，预览按需在手机上生成；不复制整套原始照片、不上传。
- 系统照片与视频增删变化会触发索引刷新；回到前台会重新核对已有索引，覆盖部分授权范围改变但权限枚举不变的情况，也可手动重新扫描。
- 优先使用拍摄日期；系统缺失该时间时按入库时间归档，并在首页显示数量。两个时间都缺失时不伪造日期。
- 手动导入优先读取系统/EXIF 日期，其次识别文件名中的 YYYYMMDD 或 YYYY-MM-DD 日期。无法确认时留空，可在编辑页填写。
- 自建相册导入图片会转换为长边最多 1600px 的 JPEG；系统照片预览也最多 1600px。手机原始照片不修改。
- 月历缩略图会裁成单元格形状，完整照片预览采用 contain，不裁切边缘。
- 视频使用独立类型和 ID，避免与相同编号的照片混淆；无有效日期的系统影像不会伪造日期加入年鉴，首页显示数量。Live Photo 和自动挑选最佳照片未实现。

## 备份与升级

自建相册的结构和照片使用 IndexedDB 保存，视频副本保存在应用私有文件中。纯照片导出 JSON，含视频导出 ZIP，恢复时作为新相册添加。系统年鉴引用手机原始照片与视频，源媒体删除、授权收回或设备更换后需要重新连接，不包含在自建相册备份中；请用系统相册的备份功能保管原始媒体。

v1 的 file origin 数据通过同源迁移页读取，先写入应用私有临时备份，再交给 v2 本地 HTTPS origin 的 IndexedDB。只有新数据库写入成功才清理临时备份。未修改 v1 原数据库。迁移失败会提示并保留数据；不要先卸载旧版。

开发版沿用同一签名证书 SHA-256 相同：bc1f2cbc5fbfd8a72b23d7517135eb507f89c45b861ba0da2410b060a75e4ab7。

## 安卓与构建

- minSdk 26 / Android 8.0，targetSdk 34，compileSdk 35；建议更新 Android System WebView。
- 申请 READ_MEDIA_IMAGES、READ_MEDIA_VIDEO、Android 14 部分照片与视频权限及旧系统 READ_EXTERNAL_STORAGE；只有点击连接相册时才申请。手动选图仍使用系统文件选择器。
- 不申请 INTERNET、管理所有文件或定位权限。https://flipyear.local 是 WebView 内部拦截的本地资源路径，不访问服务器。
- Android Studio：JDK 17、AGP 8.7.3、Gradle 8.9、SDK 35；工程无 Gradle Wrapper，可使用本机配置。
- Linux SDK 构建：设置 ANDROID_HOME，执行 bash build-android.sh。可用 ANDROID_BUILD_TOOLS / ANDROID_JAR 指定 SDK 路径。
- signing/flipyear-debug.jks 是开发版调试签名，别名 androiddebugkey，标准调试口令 android。只用于开发版覆盖安装。

主要源码：app/src/main/assets/index.html、yearbook.js、yearbook.css；安卓容器 MainActivity.java、MediaLibrary.java；原生小组件 MemoryWidget.java、WidgetConfigActivity.java；共享图片预览 PhotoDecoder.java、系统视频播放 VideoPlayerActivity.java、媒体授权规则 MediaPolicy.java；私有视频和归档 CustomMedia.java、AlbumArchive.java。

`python3 scripts/build-web.py` 生成自包含 FlipYear.html；网页版可手动导入，系统照片库连接仅在 APK 中可用。网页版与 APK 本地数据独立，可用自建相册备份迁移。

## 开源与验证

翻页采用固定版本 @gullabs/flipbook-core 3.2.2（MPL-2.0），无运行时依赖。对应源码和许可证见 third_party/flipbook-core；方案比较、维护状态、限制和来源见 SOURCE-REVIEW.md。

Node + Playwright + Chromium 环境下执行：

```bash
node tests/functional.cjs
node tests/yearbook.cjs
node tests/widgets.cjs
node tests/videos.cjs
node tests/custom-videos.cjs
bash tests/native-policy.sh
```

可通过 CHROME_BIN 指定浏览器。测试涵盖编辑、持久化、备份/恢复、月历闰年、卷页正反向、快慢触摸、宽屏双页、旧状态迁移、部分授权回调及小组件桥接入口。原生策略在 JVM 验证闰年、本地时区、夏令时边界、照片切换、位图预算、分类型授权及视频 ID。视频测试覆盖混合索引、时长标记、主动播放入口、封面失败、权限回滚、非法 ID、主题相册导入／保存失败回滚、ZIP 确认、重复回调及清理引用。JVM 实际执行 ZIP 二进制往返、CRC、损坏／越界／大小限制和暂存回滚；不以模拟的原生选择器等同于安卓设备通过。APK 编译、对齐、签名校验通过；浏览器原生传输使用 mock，尚未在安卓真机或模拟器安装验证桌面宿主、持久 URI 授权、权限对话框、MediaStore 和 WebView。

尚未提供回忆通知、云同步和 PDF/视频导出。
